# Alie

Alie is a friendly, free professional-tool hub. This MVP includes the first complete tool: **LinkedIn Post Maker**.

## Included

- Branded multi-page home and Writing & Social navigation
- Selective bold, italic, underline, and strikethrough formatting
- Bulleted, numbered, checklist, shortest-first, and longest-first line tools
- Seventeen copyable Unicode text styles
- Undo, redo, clear, live counts, responsive preview, and clipboard copy
- Local browser processing; draft text is not sent to a server

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000/`.

## Validate

```bash
npm test
npm run lint
npm run build:pages
```

Pushes to `main` deploy the static build through the included GitHub Pages workflow.
